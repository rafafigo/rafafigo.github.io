# Rafael Figueiredo Portfolio

Source code for my personal portfolio website.

## Quick Start

```bash
npm install
npm start
```

The website runs at `http://localhost:3000` by default.

On PowerShell, this avoids local execution-policy issues:

```powershell
.\start-dev.ps1
```

## Build

```bash
npm run build
```

## Deploy

```bash
npm run deploy
```

## Stack

- React 18
- TypeScript
- Material UI
- Framer Motion
- React Scripts
